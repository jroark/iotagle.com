about iotagle

iotagle is a search engine and reading proxy for vintage low-power computers — the kind whose browsers predate JavaScript, CSS, and modern TLS. It is inspired by Sean Malseed's FrogFind.

how it works

  • Search queries are forwarded to DuckDuckGo and the results are reformatted as plain HTML 3.2.
  • Read pages are fetched and run through a Mozilla Readability port, then stripped to bare text and links. Every outbound link routes back through this proxy so you stay in a clean reading environment.
  • Images are downscaled and re-encoded as small JPEGs or GIFs, optionally dithered to 1-bit for black-and-white screens.
  • Wikipedia shortcut: prefix a query with w: or wiki  to jump straight to a transcoded article.

what we don't do

  • No HTTPS. The whole point is being reachable by browsers that can't negotiate modern TLS.
  • No JavaScript, no CSS, no images on this site itself.
  • Nothing is logged beyond standard nginx and systemd journal output. We don't track visitors and we don't run analytics.

colophon

Content is not ours. Links point back to the original sources. iotagle is free software running on a single small AWS server.
